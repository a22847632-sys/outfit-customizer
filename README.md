# 👗 Outfit Customizer

Outfit Customizer is an interactive fashion styling web application built using **HTML, CSS, JavaScript, and jQuery**. It allows users to create personalized outfits by mixing and matching different clothing items and accessories.

## ✨ Features

- 👕 Select different Tops
- 👖 Choose Bottoms
- 👟 Select Shoes
- 👜 Add Accessories
- 🎨 Customize outfit colors
- 🔍 Search clothing items
- 🗂️ Filter items by category
- 🎲 Generate random outfits
- ❤️ Save favorite looks
- 🔄 Reset outfit
- ✨ Smooth animations and interactive UI
- 🖥️ Live outfit preview

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
